# Data honesty playbook

Only use rows in the normalized `output/dynamic/report-data.json` (from `input/data/` exports, directly referenced `File.Contents(...)` CSV files, or simple PostgreSQL tables/views). PBIP does not itself guarantee underlying data rows. Direct CSV/PostgreSQL rows are raw source data, not Power Query/DAX results. Never synthesize business numbers. A field name, measure expression, or visual binding is not a row-level dataset. If a visual cannot be populated faithfully, display an explicit empty state saying why. Keep missing data, ambiguous joins, unimplemented Power Query/DAX, and unsupported interactions in a limitations list. Never read `.env` or connect to external services yourself. Dynamic HTML may fetch only its localhost `report-data.json`; static HTML must make no runtime requests. Static HTML is a disclosure of all embedded data, not a secure container.
