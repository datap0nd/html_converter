# Data honesty playbook

Only use rows in the normalized `output/dynamic/report-data.json`. A `desktop-model-export` dataset contains tables exported from Power BI Desktop after Power Query and model processing; it does not contain evaluated DAX measures for every visual/filter context. A `raw-*` dataset is source data before later Power Query steps and DAX. PBIP alone does not guarantee rows. Never synthesize business numbers. A field name, measure expression, or visual binding is not a row-level dataset. If a visual cannot be populated faithfully, display an explicit empty state saying why. Keep missing data, ambiguous joins, unimplemented DAX, and unsupported interactions in a limitations list. Never read `.env` or connect to external services yourself. Dynamic HTML may fetch only its localhost `report-data.json`; static HTML must make no runtime requests. Static HTML discloses all embedded data.
